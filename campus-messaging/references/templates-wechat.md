# 微信消息模板 — 给老师 / HR 的分寸感

微信不同于邮件：更即时、更口语，但**给老师/HR发微信仍然要保留基本的正式感**，不能等同于跟同学聊天。核心原则：**先自我介绍，分条发送不刷屏，避免语音轰炸，别用表情包和网络梗**。

## 通用结构（适用于第一次联系或正式事务）

微信消息建议**拆成2-3条**依次发送，而不是一大段文字堆在一起（对方在手机上阅读大段文字体验很差），大致结构：

1. 第一条：称呼 + 自我介绍（"XX老师您好，我是XX班级的XXX"）
2. 第二条：事由说明（简明扼要）
3. 第三条：具体请求/问题，结尾加礼貌用语

### 示例：第一次加老师微信后自我介绍
```
[老师称呼]您好！

我是[院系][班级]的学生[姓名]，[如是被推荐/扫码添加：经XX介绍/扫码添加了您的微信]。

[事由，如：想向您请教一下关于XX的问题/想咨询XX事宜]，方便的时候麻烦您指点一下，谢谢老师！
```

### 示例：给老师发请假/事务性消息
```
[老师称呼]您好，打扰您了！

我是[班级][姓名]，因为[事由]，[具体请求，如：想请假一天/想跟您确认一下XX时间]。

麻烦您方便的时候回复我一下，谢谢老师！
```

### 示例：给HR/面试官发消息（面试后跟进或补充材料）
```
[HR称呼]您好！

我是[姓名]，之前投递/面试了[岗位名称]。[事由，如：想跟进一下进展/补充一份材料]。

[附上文件时说明文件是什么]，麻烦您查收，谢谢！
```

## 微信沟通注意事项

- **不要用语音轰炸**：给老师/HR发消息优先用文字，除非对方明确说可以发语音；文字方便对方随时查看、检索，语音则往往要专门找时间听。
- **不要连环追问**：发出消息后如果对方没有立刻回复，不要在几分钟内连续发好几条催促消息（"在吗""在吗？""老师在吗？？"），这是热搜里被吐槽最多的行为之一；给出合理等待时间（建议1个工作日以上）再礼貌跟进一次。
- **避免表情包和网络流行语**：正式事务沟通中不用夸张表情包、"绝绝子""家人们"这类网络用语，保持简洁书面的语气。
- **时间意识**：尽量避免深夜/凌晨发消息并要求立即处理；如果是白天发的消息，晚上对方没回也不必焦虑催促。
- **文件传输**：通过微信发送文件时，文件命名同样要规范（"姓名_事由.pdf"），并在消息里说明这是什么文件，不要甩一个文件不做任何说明。
- **群消息求助**：在班级群/工作群里@老师提问前，先想清楚问题是否只有老师能回答；能私聊解决的事，尽量不占用群聊资源，除非是需要全班/全组都知晓的公共事项。
- **什么时候该改用邮件**：如果事情比较正式、需要留存记录（如请假证明、申请材料、成绩问题），即使先用微信沟通过，也建议之后补发一封邮件确认，方便双方留痕。
