# 电话话术模板 — 请假 / 确认 / 催办

电话沟通的核心难点是**临场组织语言**，学生常见问题是：一接通就语无伦次、忘了自我介绍、说完事情匆忙挂断没有确认对方理解。以下话术按"开场白 → 核心内容 → 确认/结束语"三段式组织，可以在打电话前默读一遍打底稿。

## 通用三段式结构

1. **开场白**：问好 + 自报身份（姓名+身份，让对方第一时间知道你是谁）
2. **核心内容**：说明来意，一次说清楚，避免对方追问才想起补充信息
3. **确认/结束语**：复述关键信息确认双方理解一致，礼貌道谢结束

---

## 1. 请假电话（打给老师/导员）

```
开场白：
"[老师称呼]您好，打扰您了，我是[院系][班级]的学生[姓名]。"

核心内容：
"我想跟您请假，因为[事由]，具体是[日期]的[课程名称/几点到几点]。[如有需要：我会尽快把请假证明补给您/我会找同学帮忙记录课程内容]。"

确认/结束语：
"那我这边[日期]就不到课/不参加了，麻烦您登记一下，谢谢老师！"
```

### 注意事项
- 开口先说清楚"我是谁"，不要一上来就讲事情，对方还没反应过来你是谁。
- 提前想好请假的具体日期和事由，避免电话里support磕巴半天。
- 如果对方没接电话，考虑补发一条微信或邮件说明，避免只打电话没有留下书面记录。

---

## 2. 确认电话（面试时间确认 / 材料确认）

```
开场白：
"您好，我是[姓名]，之前投递了贵公司[岗位名称]的职位/收到了面试通知。"

核心内容：
"想跟您确认一下[事由，如：面试的具体时间和地点/需要准备的材料]。"

确认/结束语：
"好的，那我[日期][时间]准时到，谢谢您，再见！"
```

### 注意事项
- 打电话前先把要确认的问题在纸上/备忘录列好，避免挂了电话才想起漏问。
- 电话中如果对方语速较快没听清，直接礼貌请求重复，不要不懂装懂挂了电话再纠结。

---

## 3. 催办电话（询问进度，语气务必委婉）

```
开场白：
"您好，我是[姓名]，之前[事由，如：投递了简历/提交了申请材料]，不好意思打扰您。"

核心内容：
"想跟您确认一下目前的进展，方便的话麻烦告知一下大概时间，如果需要我补充材料我也可以随时配合。"

确认/结束语：
"好的，那我再耐心等您的消息，谢谢您，打扰了！"
```

### 注意事项
- 催办电话最容易显得不礼貌，语气一定要委婉，落点在"询问"而不是"催促"。
- 如果对方明确说了预计时间，不要在这之前反复致电催问。
- 电话催办后，建议再补发一条微信/邮件简短总结通话内容，方便双方都有记录。

## 通用电话礼仪提醒

- 尽量在工作时间拨打电话（一般9:00-18:00之间），避免午休、深夜时段。
- 拨打前先想清楚要说什么，避免长时间沉默或重复啰嗦。
- 如果是重要事务（如请假、申请材料），电话沟通后最好用微信或邮件补一份文字记录，避免"口说无凭"。
