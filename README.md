# campus-messaging.skill

校园/职场消息写作技能（Codex Skill）：帮助大学生写出得体规范的邮件、微信消息和电话话术，并提供闲聊润色、初稿修改、超礼貌模式等快捷功能。

## 安装

通过 Codex 的 skill 安装器安装：

```powershell
python install-skill-from-github.py --repo Sulphone-Yang/campus-messaging.skill --path campus-messaging
```

安装后，在 Codex 中触发 `$campus-messaging` 即可使用。

## 模式与快捷指令

直接在对话里输入斜杠指令进入对应模式：

| 指令 | 模式 | 作用 |
|---|---|---|
| `/润色` | 微信闲聊润色 | 不管发什么，都改写成更有礼貌的微信消息，保留聊天感和原意 |
| `/改稿` | 初稿修改 | 在用户初稿基础上修改，不重写，附改动说明 |
| `/超礼貌` | 超礼貌模式 | 对任何人都非常礼貌，默认使用标准礼貌 |
| `/标准礼貌` | 超礼貌·标准 | 正式、克制、不用表情包和颜文字 |
| `/活人感` | 超礼貌·活人感 | 礼貌但口语化，允许颜文字，更像真人聊天 |
| `/模式` | 模式列表 | 查看所有可用模式和指令 |
| `/退出` | 退出模式 | 回到默认流程 |

## 使用示例

### 闲聊润色（`/润色`）

输入：

```text
/润色 帮我问老师作业什么时候交
```

输出：

```text
能麻烦您帮忙问一下老师，作业大概什么时候交吗？谢谢！
```

### 初稿修改（`/改稿`）

输入初稿后，技能会在保留原意的基础上修改，并给出改动说明，例如补称呼、调整语气、修正结尾。

### 超礼貌（`/超礼貌 /活人感`）

输入：

```text
/超礼貌 /活人感 帮我问问同学明天几点到
```

输出示例：

```text
哈喽～想请问一下你明天大概几点到呀？我好提前过去等你 (๑•̀ㅂ•́)و✧ 麻烦你啦！
```

## 默认流程

没有进入任何模式时，技能会先主动询问渠道、对象、事由、语言和关键细节（姓名、班级、学号、日期等），确认清楚后再起草，不会只丢一个带方括号的模板让用户自己填。
