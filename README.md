# campus-messaging.skill

校园/职场消息写作技能（Codex Skill）：帮助大学生写出得体规范的邮件、微信消息和电话话术。**写邮件是核心功能**，同时提供闲聊润色、初稿修改、超礼貌、自动回复等快捷功能。语气由可调的活人值/礼貌值控制，并内置反AI风格引擎降低“AI味”。

## 安装

通过 Codex 的 skill 安装器安装：

```powershell
python install-skill-from-github.py --repo Sulphone-Yang/campus-messaging.skill --path campus-messaging
```

安装后，在 Codex 中触发 `$campus-messaging` 即可使用。

## 核心功能：写邮件

写邮件是这个技能最重要、优先级最高的功能。直接说“帮老师写封请假邮件”“给导师写封申请邮件”“给HR写封自荐邮件”即可，技能会读取邮件模板，先主动询问缺失信息，再输出主题行、正文和落款。也可以输入 `/写邮件` 进入该模式。

## 使用中帮助

在对话中直接输入 `/help`、`/帮助` 或 `/bz`，技能会给出当前可用指令、预设列表和最简单的使用方式；`/帮助 写邮件` 可以查看具体模式说明。

## 活人值与礼貌值

默认设置：**活人值 60%，礼貌值 80%**。数值决定消息的“真人感”和“礼貌程度”：

- 活人值 0-20：公文感，几乎没有语气词
- 活人值 40-60：日常口语，偶尔用“呀/啦”
- 活人值 60-80：明显口语化，可用“～”
- 活人值 80-100：像真人闲聊，允许颜文字
- 礼貌值 0-40：随意、接近朋友语气
- 礼貌值 40-70：普通礼貌，用“请/谢谢”
- 礼貌值 70-90：明显礼貌，用“您/麻烦您”
- 礼貌值 90-100：非常礼貌，称呼和结尾都很周到

设置会保存到 `campus-messaging/settings.json`，跨会话持续生效。

## 反AI风格引擎

V0.06 起，活人值/礼貌值按 `campus-messaging/references/human-style-engine.md` 的旋钮表运作，不再只是百分比：

- 活人值控制口语密度、长短句交替、语气词、碎片句、颜文字和自我修正
- 礼貌值控制称呼、敬语、请求软化、致谢和结尾余地
- 输出前必跑反AI检查：禁用“首先/其次/综上所述/希望以上对您有帮助/作为一名AI/不仅仅...更是...”等 AI 味词句
- 人类方向：长短句交替、话说到一半、自我纠正、具体细节、“然后/结果/其实/反正”式连接

## 个人风格叠加层（Asulphone）

V0.07 起默认开启个人语言风格叠加层，规则见 `campus-messaging/references/personal-style-asulphone.md`：

- 第一人称学长口吻：我 / 本人 / 咱
- 短句短段，一段只说一件事
- 感叹/疑问驱动，允许“？？？”和“啥时候”
- 自嘲玩梗词库：麻了、离谱、好家伙、那没事了、属于是、省流、……、~
- 公众号/长文加粗关键信息、编号列表、“省流：”和固定签名
- 正式邮件保留礼貌，但用短段落，不强行玩梗

控制：`/我的风格`（`/wdfg`）查看，`/我的风格 开` 开启，`/我的风格 关` 关闭。

## 快速切换预设

```text
/预设              查看所有预设
/预设 写邮件       活人20 礼貌95，写正式邮件（核心）
/预设 标准礼貌     活人10 礼貌95，正式事务用
/预设 活人感       活人80 礼貌85，礼貌但像真人
/预设 闲聊         活人65 礼貌75，日常润色
/预设 自动回复     活人60 礼貌80，粘贴消息直接回
/设置 活人70 礼貌85  手动自定义
/恢复默认          回到活人60 礼貌80
/记住 姓名=张三 班级=24跨传x班 学号=24xxxxxxx  保存个人资料
```

所有指令都有拼音快捷键，例如 `/zdhf` 等于 `/自动回复`，`/xyj` 等于 `/写邮件`。

## 使用示例

### 闲聊润色（`/润色`）

输入：

```text
/润色 帮我问老师作业什么时候交
```

输出：

```text
能麻烦您帮忙问一下老师，作业大概什么时候交吗？谢谢！
```

### 初稿修改（`/改稿`）

输入初稿后，技能会在保留原意的基础上修改，并给出改动说明，例如补称呼、调整语气、修正结尾。

### 自动回复（`/自动回复`）

输入：

```text
/自动回复 老师：新苗课题结题论文8月下旬发我下？
```

输出示例：

```text
好的，谢谢老师！我会在8月下旬前整理好发给您。
```

### 超礼貌（`/超礼貌 /活人感`）

输入：

```text
/超礼貌 /活人感 帮我问问同学明天几点到
```

输出示例：

```text
哈喽～想请问一下你明天大概几点到呀？我好提前过去等你 (๑•̀ㅂ•́)و✧ 麻烦你啦！
```

## 默认流程

没有进入任何模式时，技能会先主动询问渠道、对象、事由、语言和关键细节（姓名、班级、学号、日期等），确认清楚后再起草，不会只丢一个带方括号的模板让用户自己填。
